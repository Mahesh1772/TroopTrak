## 🌐 GitHub Pages Setup

### How to Enable GitHub Pages

1. **Push the documentation to GitHub:**
   ```bash
   git add firebase_project_2/docs/
   git commit -m "docs: add comprehensive documentation for TroopTrak"
   git push origin main
   ```

2. **Enable GitHub Pages:**
   - Go to your repository on GitHub
   - Click **Settings**
   - Scroll to **Pages** section (left sidebar)
   - Under "Source", select:
     - **Branch:** `main` (or your default branch)
     - **Folder:** `/docs`
   - Click **Save**

3. **Access your documentation:**
   - Your documentation will be available at:
     ```
     https://[your-username].github.io/[repository-name]/
     ```
   - Example: `https://bsiva.github.io/TroopTrak/`

4. **Wait for deployment:**
   - GitHub will take 1-5 minutes to build and deploy
   - You'll see a green checkmark when ready

## 🔧 Customization Options

### Changing the Theme

Edit `docs/_config.yml`:

```yaml
theme: jekyll-theme-cayman  # Change this line

# Available themes:
# - jekyll-theme-cayman (current - modern, clean)
# - jekyll-theme-minimal (simple, minimal)
# - jekyll-theme-architect (header focus)
# - jekyll-theme-slate (dark theme)
# - jekyll-theme-modernist (modern style)
```

### Adding Custom CSS

Create `docs/assets/css/style.scss`:

```scss
---
---

@import "{{ site.theme }}";

/* Your custom styles */
.main-content {
  max-width: 1200px;
}

h1 {
  color: #8147e6;
}
```

### Adding Logo

1. Add logo image to `docs/assets/images/logo.png`
2. Update `_config.yml`:
   ```yaml
   logo: /assets/images/logo.png
   ```
